# なんだっけAI

**会話や動画を一緒に聞いておいて、知らない言葉が出たら「あなた向けに」解説してくれるアプリ（PWA）**

会議、講演、病院の説明、ニュース、YouTube。知らない言葉が出てきても、話は止まってくれません。
なんだっけAIは、スマホを置いておくだけで音声を聞き、**あなたが知らなさそうな言葉だけ**を拾って解説します。ちらっと画面を見れば、もう答えが出ています。

## 特徴

| | |
|---|---|
| 🎙 聞いておいてくれる | 自分で調べなくていい。話を聞くことに集中できる |
| 👤 その人向け | 年齢・仕事・得意分野に合わせて「どの言葉を」「どのくらいやさしく」解説するかが変わる |
| 🌱 一緒に育つ | 「知ってた」を押した言葉は次から出ない。何度も出る言葉は「◯回目」と教えてくれる。出会った言葉は自分だけのじしょにたまる |
| 🔎 くわしく | もっと知りたい言葉は、背景や関連語までくわしく解説 |
| 📺 動画にも | PCやテレビのそばに置けば、YouTubeや配信の音声にも使える |

## 使い方

1. 公開URLをスマホで開き、「ホーム画面に追加」
2. 設定タブで「あなたのこと」と Claude APIキー を保存
3. 「聞きはじめる」を押して、話や動画のそばに置く

対応ブラウザ：Android / PC の Chrome、iPhone の Safari

## プライバシー

- 音声はブラウザの音声認識で文字になり、**解説のときに文字だけ**が Anthropic の Claude API に送られます（録音は保存しません）
- じしょと設定は**この端末のブラウザ内にだけ**保存されます
- まわりの人と話すときは、聞いていることを相手に伝えて使ってください

## 技術

- HTML / CSS / JavaScript のみ（ビルド不要）、GitHub Pages で公開
- 音声 → 文字：ブラウザ標準の Web Speech API（無料）
- 言葉の選定と解説：Claude API（`claude-opus-5-5`）＋ 構造化出力（JSON Schema）
  - 数秒ごとに「新しく聞こえた部分」＋「直前の文脈」＋「利用者のプロフィール」＋「知っている言葉リスト」を送り、この人が知らなさそうな言葉だけを返させる

## これから（構想）

- **YouTube拡張機能**：字幕から先回りで解説を出し、動画の上に表示
- **ARグラス / イヤホン**：画面を見なくても、目の前やイヤホンでそっと教えてくれる
- **育つ先生**：じしょの履歴から、その人の「知っていること」をAIが理解し、説明がどんどんその人向けになる
- **学び直し**：たまった言葉で、すきま時間にクイズ

> 「知らない言葉」で置いていかれる人をなくす。AIがそばで一緒に聞いて、一緒に育つ。
